# Preview

`intentshark-preview.html` is a single self-contained HTML file containing the
whole site: both pages and the working scanner, with all styles and scripts
inlined.

To view it, download the file and open it in a browser. No server, build step,
or deployment is needed.

This is only a convenience preview for local viewing. The real site is the Astro
source in this repo, built and published by the deploy workflow.
